# NestJS Microservices Example

Цей проєкт демонструє реалізацію мікросервісної архітектури за допомогою NestJS. Комунікація між сервісами відбувається через **RabbitMQ**, а дані зберігаються в окремих **локальних базах даних**.

## Необхідні умови

1. **Три локальні бази даних** (наприклад, PostgreSQL) зі створеними БД:
   - `customer`
   - `book`
   - `order`

2. **RabbitMQ**:
   - Створити свій екзмепляр, та замінити URL на свій. (наприклад, на сервісі https://www.cloudamqp.com)

## Встановлення

У корені кожного сервісу виконай:

```bash
npm install
```

## Запуск сервісів

Запусти кожен Nest-сервіс окремо в його директорії:

```bash
npm run start:dev
```

Сервіси будуть доступні на портах:
- `3000` – Customer Service
- `3001` – Book Service
- `3002` – Order Service
